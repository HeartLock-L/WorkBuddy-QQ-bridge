# 离线测试

`test_attachment_limits.py` 检查 10 MiB 边界、累计大小、超时取消、GIF 抽帧与损坏处理；`test_attachment_routing.py` 检查来源信息与动图说明随普通问答和审批任务传递；`test_idle_attachments.py` 检查闲聊图片下载限额与 GIF 通路。`test_attachments.py` 检查附件落盘、来源标记、引用图片、等待补图和群/发送者匹配；`test_message_routing.py` 检查命令优先级、空回复仍消费命令以及禁止发送时不继续进入普通问答。

`test_quoted_replies.py` 检查明确 @ 后引用本条消息、并发请求各自归属、@全体/私聊/戳一戳/无效标识的普通回复，以及引用或图片组件构造失败时的回退。`test_meme_collection.py` 检查 QQ 表情标记、同群收藏、去重、限额、名称随图清理与孤立索引清理；`test_meme_library.py` 检查语境候选召回、名称学习与重载复用、控制标记清理、跨群和失效名称拒绝、文件变化与链接保护、冷却和并发限频；`test_meme_routing.py` 检查挑图只用原有一次模型请求、文字与表情同条发送、有效纯表情与原消息引用、名称学习失败不阻断文字、跨群选择拒绝、失败与过期回复不附图，以及收藏的开关、暂停和身份检查。

`test_reply_text.py` 检查文本处理拆分后，面板长度限制、过滤开关、过滤词和拒绝文案仍即时生效；`test_source_reload.py` 检查修改提示词、回复过滤及源码清单会触发实际热重载巡检。诊断和打包测试同时核对这些新模块参与完整性与版本检查。

`test_gateway_discovery.py` 检查动态端口发现、凭据变化、扫描退避与认证判据；`test_bridge_status.py` 检查运行心跳的白名单字段、原子写入、生命周期与隐私。问答集成测试同时覆盖闲聊暂停后的恢复条件，诊断测试覆盖心跳过期、版本与存活分离以及动态网关检查。

`test_cache_cleanup.py` 检查临时目录与闲聊图片的清理范围、保留期、上限、路径与链接保护，以及无消息时的定期维护、取消和卸载等待；所有删除测试只使用临时测试目录。

`test_request_queue.py` 检查先进先出、容量、取消和跨实例互斥；`test_question_scheduling.py` 检查模拟网关下的排队、远端任务恢复、状态分类和主动回复时效；`test_jimeng.py` 检查独立即梦模块；`test_image_jobs.py` 检查原子存储与跨进程互斥；`test_image_retention.py` 检查自拍保留、24 小时临时副本、清理路径和重解析保护、失败重试；`test_image_retention_routing.py` 检查正常回图及管理员处理后的清理、自拍入口标记和清理后不重新生图；`test_image_job_archive.py` 检查终态归档、冲突、中断和锁内复查；`test_image_job_commands.py` 检查查询范围、管理员处理、原会话补发、去重与停止；`test_draw_recovery.py` 检查重启恢复、取消、原群投递和不明结果隔离；`test_artifact_isolation.py` 检查任务结果与回图来源；`test_receipts.py` 检查回复回执和执行入口权限；`test_bridge_lifecycle.py` 检查暂停和生命周期；`test_diagnostics.py`、`test_operations.py` 检查维护工具；`test_build_material.py` 检查部署清单与脱敏。

`bridge_selftest.py` 是部署自检入口，按功能调用 `selfcheck/` 中的检查，保留当前聊天规则、触发、权限与生图入口的完整逻辑自检及 `ALL PASS` 结果标识，不参与 unittest 自动发现。

公共测试工具集中在三个文件：`bridge_test_support.py` 负责从插件中加载指定定义，`artifact_test_support.py` 提供生图任务的模拟环境，`diagnostic_test_support.py` 提供诊断脚本的离线保护。测试文件各自保留断言，不再借用其他测试文件作为工具库。插件定义缺失时加载器会立即报错，避免改名后漏测。

源码目录和开发包运行 `scripts/test-bridge.bat` 可执行完整离线回归与部署自检。默认运行包只保留 `bridge_selftest.py` 和 `selfcheck/`，脚本会明确提示仅运行部署自检，不将缺少开发测试显示成完整回归通过。需要完整回归时使用开发包，或保留维护者源码目录。

全部测试使用模拟外部接口，不进行真实生图、模型调用、QQ 发送或真实进程终止。运行包与开发包都不含构建脚本中的本机脱敏对照，开发包中的构建器测试会明确跳过。doctor 使用的部署自检在两种包中都保留。

旧 ACP 通道测试和一次性线上探针已经清理；历史副本在本机 backups 恢复包中。

长期记忆回归覆盖 `test_memory_store.py`、`test_memory_service.py` 和 `test_memory_routing.py`：持久化、可信会话范围、来源校验、修订/遗忘及在途旧批次、故障降级、空闲检查和实际入口接线；同时检查平时只本地收录分类、旧自动整理配置不能启动模型、管理员手动开启与停止、启动时消息上界、后续消息留待下轮、持久退避与人工开启的边界，以及主题目录与详情分页、简介检索、更正/遗忘后的即时更新。使用临时数据库与模拟模型，不读取正式记忆，不发送 QQ 消息。

群与成员分层记忆检查还覆盖：原消息时间和接收时间、本地消息类型和主题线索、非提炼记录、同群时间线和多成员来源、手动任务空闲检查、群目录与个人子目录、上下文引用失效、schema 4 升级与中断回滚、旧实例写入隔离。分类标签不直接升格为长期记忆，手动轮次的消息上界同时限制主来源和上下文。生命周期检查包含不响应取消的任务、有截止时间但不丢线程追踪的记忆关闭，以及旧记忆任务完成后才重载。

`test_memory_control.py` 使用临时项目和模拟运行状态检查本机开始、停止、状态入口及控制请求；不会访问正式网关或启动实际模型整理。部署与开发材料均包含控制入口，但不包含数据库、控制请求或处理中的运行文件。
