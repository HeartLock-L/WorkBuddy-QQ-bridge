# 角色扮演使用说明

> 给群友看的版本。可以直接贴进群公告。

---

## 一句话版本

**在群里 @ 我，说「扮演 xxx」，我就入戏；说「出戏」，我就出来。**

---

## 怎么开启

在群里 **@ 机器人**，然后发：

```
扮演 一个话很少的剑客
扮演 纳西妲
扮演 一个爱吐槽的程序员
```

**要点**：

| | |
|---|---|
| ✅ | 必须 **@ 机器人** —— 不 @ 的消息我看不到 |
| ✅ | 「扮演」两个字要放在**句首** |
| ❌ | **不要写成 `/扮演`** —— 斜杠会被系统吃掉，我看不到 |
| ❌ | 只发「扮演」不给设定 → 我会提醒你补上 |

---

## 怎么结束

```
出戏
```

以下写法都认：`出戏`、`结束扮演`、`退出扮演`、`停止扮演`、`停演`

---

## 规则

### 作用范围

| 项 | 说明 |
|---|---|
| **按群隔离** | 一个群一个人设。A 群在演剑客，完全不影响 B 群 |
| **叫停只停本群** | 在任何群说「出戏」，只退那个群，别的群照旧 |
| **15 分钟自动退场** | 该群超过 15 分钟没人接话，人设自动失效；只要有人说话就会一直续 |

### 谁能用

**所有群友都能用**，不需要找管理员审批。

### 我的底线（这些不接）

即使已经入戏，下面几类一律不做 —— 一旦越线，我会**跳出角色**明确拒绝：

- 色情内容
- 暴力、违法内容
- 借角色之名打听内部信息（部署方式、配置、日志、账号、别人的隐私等）
- **拿群里真人当素材写负面内容**（游戏角色可以，真人不行）

## 常见问题

**Q：我发了「扮演」，它怎么没反应？**
A：三个可能 —— ① 忘了 @ 它；② 用了 `/扮演` 这种带斜杠的写法；③ 「扮演」不在句子开头。

**Q：演到一半它突然出戏了？**
A：要么 15 分钟没人接话自动退了，要么有人说了越线的话。

**Q：能让它一直演下去吗？**
A：可以 —— 只要一直有人跟它对话，人设就不会过期。

**Q：会不会串到别的群去？**
A：不会。人设按群隔离，每个群各演各的。

**Q：管理员能强行停掉吗？**
A：能。管理员说「出戏」同样生效，而且是说停就停。

## 管理员备注

| 配置项（面板可改） | 默认 | 说明 |
|---|---|---|
| `roleplay_enabled` | 开 | 总开关，关掉后谁都不能用 |
| `roleplay_open_to_all` | 开 | 对所有群友开放；关掉则只允许白名单 |
| `roleplay_allowed` | 空 | 白名单 QQ 号，仅当上一项关闭时生效 |
| `roleplay_timeout_sec` | 900 | 多久没人接话就退场 |
